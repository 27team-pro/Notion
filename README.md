# 27TEAM — Notion

Assets for 27TEAM Notion templates. [27team.pro](https://27team.pro)

## ClearCRM

Marketing CRM template for Notion.

- `clearcrm/icons/` — pixel icon set (9×9 grid) in four variants: `tile` (white on black, used in the template), `black`, `white`, `svg`
- `clearcrm/covers/` — page covers, 1500×600
- `clearcrm/marketplace/` — Notion Marketplace images, 1920×1080
- `clearcrm/src/` — scripts that generate all of the above (`python3 clearcrm/src/icons.py`)

Icons are served via GitHub Pages: `https://27team-pro.github.io/notion/clearcrm/icons/tile/<name>.png`
